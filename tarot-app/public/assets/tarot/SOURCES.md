# Tarot Image Sources

The card face images in this folder are Rider-Waite-Smith major arcana scans
downloaded from Wikimedia Commons via `Special:Redirect/file/...`.

Wikimedia Commons notes that the original Rider-Waite tarot deck is public
domain in both the United States and the United Kingdom, while some later
colorized versions can remain copyrighted.

Source category:
https://commons.wikimedia.org/wiki/Category:Rider-Waite_tarot_deck

The card back image, `card-back.svg`, is a custom app asset created for this
project and is not copied from the Universal Waite or any commercial deck back.
